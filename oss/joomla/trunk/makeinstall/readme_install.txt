欢迎使用由 [OSS计算技术] 开源社区贡献的相关软件产品和资料。

请在遵守开源软件协议的基础下使用本计算机软件产品。

需要说明的是，本语言包是在很多以前版本的基础上逐步扩充合并的。

非常感谢相关版本的最初翻译的提供者。

为了更好的普及 Joomla 的使用，降低广大用户的使用难度。

我们在原中文安装包的基础上制作了这个汉化包。

为了你系统的安全，我们不对其他核心的文件和库进行打包。这样可以避免影响到你系统的使用。

因为在默认安装程序中，如果你愿意的话会插入英文的 DEMO 数据。

那么很多朋友在使用的时候就有点找不到北了。因为很多数据是写入数据库的。

我们同时也对 SQL 进行了中文化的处理了。
