Ant targets

You can use the Ant targets to transform DITA to several different output formats.

  • dita2docbook
    Use the dita2docbook target to generate DocBook.
  • dita2eclipsecontent
    Put your short description here; used for first paragraph and abstract.
  • dita2eclipsehelp
    Use the dita2eclipsehelp target to generate Eclipse help.
  • dita2htmlhelp
    Use the dita2htmlhelp target to generate HTML help.
  • dita2pdf
    Use the dita2pdf target to generate a Portable Document Format (PDF) file.
  • dita2javahelp
    Use the dita2javahelp target to generate JavaHelp.
  • dita2troff
    Use this target to generate TROFF.
  • dita2wordrtf
    Use the dita2wordrtf target to generate Rich Text Format (RTF).
  • dita2xhtml
    Use the dita2xhtml target to generate XHTML.
