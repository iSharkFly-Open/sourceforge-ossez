验证你的Java安装

尽管Maven可以运行在Java 1.4上，但本书假设你在至少Java 5上运行。尽管使用你操作系统上最新的稳定版本的JDK。本书的例子在Java 5或者Java 6上都能运行。 

C:\Documents and Settings\YUCHENGHU>java -version
java version "1.5.0_21"
Java(TM) 2 Runtime Environment, Standard Edition (build 1.5.0_21-b01)
Java HotSpot(TM) Client VM (build 1.5.0_21-b01, mixed mode, sharing)

C:\Documents and Settings\YUCHENGHU>

Maven能在所有的验证过的JavaTM 兼容的JDK上工作，也包括一些未被验证JDK实现。本书的所有样例是基于Sun官方的JDK编写和测试的。如果你正在使用Linux，你可能需要自己下载Sun的JDK，并且确定JDK的版本（运行 java -version）。目前Sun已经将Java开源，因此这种情况将来有希望得到改进，将来很有可能Sun JRE和JDK会被默认安装在Linux上。但直到现在为止，你还是需要自己去下载。
